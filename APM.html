4. Endpoint Security & Vulnerability Remediation

Entra ID & BitLocker
⚡ 5-Second Brain Glances:
Conditional Access → Silent BitLocker via Intune → Sign-in log triage → Protecting health data.

Likely Question: "How do you ensure endpoints are secure, specifically around MFA, encryption, and access management?"

🗣️ What to Actually Say:

"Especially in a human services company like APM, data security on a remote laptop is paramount. My approach relies entirely on Conditional Access tied to device compliance.

I ensure that BitLocker is deployed silently via Endpoint Security policies in Intune, with recovery keys escrowed directly to Entra ID so the helpdesk isn't locked out. If a device fails compliance—say, an antivirus definition drops or BitLocker is suspended—Conditional Access automatically revokes their M365 session tokens until the device is remediated.

When dealing with vulnerabilities, I don't just pass tickets along. If we get MFA loops or access failures, my first stop is the Entra ID Sign-in logs cross-referenced with Intune device state. I diagnose the exact policy conflict—whether it's a stale compliance token or an untrusted IP location—and implement the fix at the architectural level rather than just resetting the user."
